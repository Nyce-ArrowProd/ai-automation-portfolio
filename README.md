## Key Principles I Build By

- **Gate before writing** — confidence checks and validation run before any data gets logged or routed
- **Automate the decision, not just the task** — conditional logic and AI classification replace manual sorting
- **Low-confidence flags are features** — uncertain output routes to human review, not silent failure
- **Document everything** — every build includes a clear trail of what it does and why
