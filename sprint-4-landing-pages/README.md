# Sprint 4 — AI-Generated Local Service Landing Pages

**Tools:** Lovable.dev · AI Image Generation · HTML/CSS
**Sprint:** 4 of 7 | TripleTen AI Automation Bootcamp

---

## The Problem

Local service businesses often have no web presence, or have outdated pages that do not convert. Building custom landing pages takes time and design skill most small operators do not have.

---

## What I Built

Local service landing pages built using AI-assisted tools — demonstrating how non-developers can deploy professional, functional web pages using AI generation workflows.

Each page includes:
- AI-generated hero visuals tailored to the service
- Clear service description and value proposition
- Contact and call-to-action sections
- Mobile-responsive layout

---

## Approach

Used Lovable.dev to scaffold and generate page structures, with AI image generation to produce custom visuals for each service type. The process demonstrates how an AI Automation Specialist can deploy client-facing assets without a dedicated design or development team.

---

## Key Learnings

- AI-assisted tools lower the barrier to deployment but require clear prompting to produce usable output
- Generated visuals need quality review — AI image output varies significantly based on prompt specificity
- The value is in the workflow: prompt, generate, review, deploy — repeatable across clients and service types
